# AGENTS.md

## Project

Next.js 15 (App Router) + React 19 + TypeScript + shadcn/ui (new-york style) + Tailwind CSS v3.
Generated by v0.app. Deployed on Vercel.
Package manager: **pnpm** (pnpm-lock.yaml present).

## Commands

- `pnpm dev` — start dev server
- `pnpm build` — production build (TS errors are ignored via `next.config.mjs`)
- `pnpm start` — serve production build
- `pnpm lint` — ESLint

No test runner, no typecheck script, no formatter configured.

## Architecture

- **Entry**: `app/layout.tsx` (root layout, dark theme default via `bg-black text-white`)
- **Dashboard**: `app/page.tsx` — client-component SPA with sidebar nav routing to 4 sub-pages via `useState` (not Next.js route navigation):
  - `app/command-center/page.tsx` — overview
  - `app/agent-network/page.tsx` — agents
  - `app/operations/page.tsx` — operations
  - `app/intelligence/page.tsx` — intel (has `loading.tsx`)
  - `app/systems/page.tsx` — systems
- **UI components**: `components/ui/` — shadcn/ui primitives (Radix-based)
- **Hooks**: `hooks/` — `use-toast`, `use-mobile`
- **Utils**: `lib/utils.ts` — `cn()` helper (clsx + tailwind-merge)
- **Path alias**: `@/*` → project root (configured in `tsconfig.json`)

## Key Quirks

- **No route-based navigation** — `app/page.tsx` uses client-side `useState` to swap sub-page components. The route subdirectories (`app/command-center/`, etc.) are NOT used as Next.js routes; they are imported directly.
- **Build ignores TypeScript errors** — `next.config.mjs` sets `ignoreBuildErrors: true`.
- **Images unoptimized** — `next.config.mjs` sets `images.unoptimized: true`.
- **Dark mode only** — layout hardcodes `bg-black text-white`. Tailwind dark mode uses `class` strategy but `.dark` class is never toggled.
- **No tests** — zero test files or test config.
- **CSS variables drive theming** — all colors in `globals.css` use HSL CSS custom properties; Tailwind config maps semantic names to these variables.
